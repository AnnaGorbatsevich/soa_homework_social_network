 Данный сервис отвечает за контент: посты и комментарии.
Получает запросы от API о создании/удалении/просмотре поста или комментария.
Может:
1. Добавить комментарий к посту
2. Добавить комментарий на комментарий
3. Поставить лайк на пост
4. Добавить просмотр на пост
5. Поставить лайк на комментарий
6. Выдать информацию по постам пользователя
7. Выдать информацию по комментариям пользователя
